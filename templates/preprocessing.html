Preprocessing

Every stage below reads from dataset/target_engineered_M2.csv (not the raw file) so all five candidate targets stay available downstream.

  • target_variable_engineering_M2.py — builds all 5 target candidates from raw data
  • clean_missing_imputer_M2.py — deletion / mean / median / forward-fill / missing-indicator
  • clean_label_encode_M2.py — label encoding for categorical predictors
  • clean_one_hot_encod_M2.py — one-hot encoding
  • clean_ordinal_encod_M2.py — ordinal encoding (exercise_intensity has a real order)
  • clean_target_encode_M2.py — mean-target encoding
  • clean_embedding_encode_M2.py — pandas-based embedding encoding
  • clean_minmax_stand_norma_M2.py — standardization / min-max / L2 normalization
  • final_preprocess_M2.py — assembles the modeling-ready dataset for one chosen target
