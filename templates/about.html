About GlucoTrend

A hands-on machine learning project for exploring continuous glucose monitoring data. It brings data inspection, feature preparation, predictive modeling, clustering, and evaluation into one browsable workspace.

Why this project

Turn a table of readings into a path you can inspect.

Glucose readings sit alongside context: recent history, insulin, meals, activity, and additional biosignals. GlucoTrend studies how that context can be prepared and examined by familiar machine learning methods.

The project is organized around transparency. The website exposes the raw dataset summary, each preprocessing stage, evaluation metrics, saved plots, and downloadable source code and outputs. This makes it easier to follow how the analysis was assembled and where each result came from.

Its benchmark data is small and synthetic/benchmark-oriented. The results are useful for learning and comparing methods, but they do not establish clinical performance or provide treatment recommendations.

Questions the analysis asks

One dataset.
Several lenses.

Targets define what a model learns to predict. Unsupervised methods explore structure without using those labels in the same way.

SUPERVISED · M3 / M5

Classification & validation

Decision Tree, Random Forest, and AdaBoost classify glucose range. Module 5 adds cross-validated evaluation to examine performance across folds.

UNSUPERVISED · M4

Clusters & embeddings

K-Means, K-Means++, DBSCAN, and hierarchical clustering explore groups. PCA and t-SNE create lower-dimensional views for inspection.

ANOMALY REVIEW · M4

Isolation Forest

Flags unusual observations relative to the feature distribution. These are candidate anomalies for investigation, not diagnoses.
