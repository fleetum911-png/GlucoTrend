Project overview

About GlucoTrend

GlucoTrend applies machine learning to continuous glucose monitoring (CGM) data to forecast future glucose readings and classify glucose-range risk, using the GlucoBench benchmark dataset (10 patients, 15,731 timestamped readings).

Objectives

  • Forecast the next CGM reading(s) from recent history and context (insulin, carbs, activity).
  • Classify glucose-range risk (in-range vs. hyperglycemia) for early alerting.
  • Compare five target-variable framings (regression, binary, 3-class, 5-class, trend) on the same feature set to see which is best supported by this dataset.
  • Cluster patient/reading profiles with K-Means to surface behavior patterns beyond the labeled targets.

Pipeline

Dataset load & missing-value audit → correlation/EDA → target variable engineering → missing-value imputation → categorical encoding (label / one-hot / ordinal / target / embedding) → scaling → final preprocessing → classification (Decision Tree, Random Forest, AdaBoost) → clustering (K-Means / K-Means++).

Technologies used

Python

Core language for the entire pipeline.

Pandas & NumPy

Data loading, cleaning, and feature engineering.

Scikit-learn

Preprocessing pipelines, classifiers, and clustering.

Matplotlib & Seaborn

EDA, confusion matrices, and cluster visualizations.

Flask

This web application, serving live data and predictions.
